=======================

Scope
-----
Code/project configuration and tests only. No UI source/resource files were changed.

Fixes applied
-------------
1. Restored the production USDT BEP-20 contract configuration:
   0x55d398326f99059fF775485246999027B3197955
2. Kept submitDeposit() in the PENDING state and ensured it does not credit spendable balance.
3. Corrected the duplicate-TxHash test so a duplicate rejected after a pending submission does not expect funds.
4. Added an explicit pending-deposit test.
5. Added a test-source-only trusted confirmed-deposit fixture for tests that legitimately require funds.
   It inserts a CONFIRMED deposit, credits the test wallet, and records a DEPOSIT ledger entry.
   No production test-funding/backdoor method was added.
6. Updated withdrawal, P2P, and cross-user tests to use the trusted confirmed fixture rather than treating
   submitDeposit() as immediately spendable.
7. Corrected the cross-user privacy assertion to verify deposit ownership instead of assuming every deposit
   must appear as a ledger entry from submitDeposit().
