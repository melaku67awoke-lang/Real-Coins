RealCoin v30 - Step 19 Backend Replacement Report

Source: Real-Coins-step18.zip

Step 19 replaces the password-reset backend foundation:
- Removed the Google Cloud Run / Firestore / Gmail SMTP backend implementation and Cloud Build deployment file.
- Added Cloudflare Worker HTTPS API with the same Android endpoint contract.
- Added D1 schema/migration for reset sessions and rate-limit state.
- Added server-side Resend email delivery via HTTPS API.
- Added server-only HMAC OTP hashing with per-session random salt.
- Added atomic D1 OTP-attempt claiming and one-time reset-token consumption.
- Preserved the short-lived Ed25519 reset authorization model and the email binding from Step 18.
- No new password is sent to or stored by the backend.
- Android UI was not changed. The backend URL placeholder now names the Cloudflare Worker instead of Cloud Run.

Verification:
- Node syntax checks performed by Step 19 packaging script.
- Backend security tests are run separately with `npm test`.
- Android Gradle build is not claimed because the repository still does not contain an executable gradlew script.
- Cloudflare deployment is not claimed; it requires the user's Cloudflare account, D1 database, Resend account/domain, and server-side secrets.
